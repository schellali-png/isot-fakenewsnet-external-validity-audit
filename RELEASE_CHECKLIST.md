# Release checklist

- [x] Scripts, protocols, and results contain no redistributed raw title or
  article text.
- [x] Input dataset hashes are recorded in the JSON configuration artifacts.
- [x] Version set to `1.0.0` and release date recorded.
- [x] `CITATION.cff`, `LICENSE`, `CHANGELOG.md`, `.gitignore`, and pinned
  `requirements.txt` are present.
- [x] Title-level near-duplicate, source-clustered bootstrap, seen/unseen
  hostname, and cleaning-sensitivity analyses are included.
- [ ] Add `repository-code` and `doi` to `CITATION.cff` after creating the
  public repository and archival record.
- [ ] Insert the public repository URL and archival DOI into the manuscript.
- [ ] Create and push Git tag `v1.0.0`.
- [ ] Archive the tagged release and record the minted DOI.
